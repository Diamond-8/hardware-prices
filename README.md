# موقع أرخص قطع الكمبيوتر

موقع عربي يعرض أرخص سعر لكل قطعة كمبيوتر من المتاجر السعودية، والأسعار تتحدث تلقائياً كل ست ساعات بدون ما تحتاج سيرفر مدفوع.

## مكونات المشروع

| الملف | وظيفته |
|---|---|
| `products.yaml` | قائمة القطع وروابطها في المتاجر (هذا الملف اللي بتعدّله أنت) |
| `scraper.py` | السكربت اللي يزور الروابط ويسحب الأسعار |
| `site/index.html` | واجهة الموقع |
| `site/data.json` | الأسعار الناتجة (يكتبها السكربت تلقائياً) |
| `.github/workflows/update-prices.yml` | التحديث التلقائي والنشر |
| `tests/` | اختبارات السكربت |

## لوحة التحكم والإحصائيات

لوحة بكلمة سر تعرض لك:

| القسم | وش يعرض |
|---|---|
| الأرقام الرئيسية | الزوار، الزيارات، ضغطات روابط المتاجر، نسبة الضغط، الزوار الجدد، متوسط مدة الزيارة، عمليات البحث، ومقارنة بالفترة اللي قبلها |
| رسم يومي | الزوار والضغطات لكل يوم |
| المتواجدين الحين | كم زائر فاتح الموقع آخر ٥ دقائق |
| أكثر القطع ضغطاً | وش القطع اللي الناس فعلاً راحوا يشترونها |
| الضغطات حسب المتجر | تفيدك لو تبي تفاوض متجر على عمولة |
| البحث | أكثر شي يدورون عليه، والأهم: اللي بحثوا عنه وما لقوه |
| أوقات الذروة | أكثر ساعة فيها زوار، عشان تعرف متى تنزل إعلاناتك |
| مصادر الزوار | قوقل، انستقرام، تويتر، أو مباشر |
| الأجهزة والمتصفحات والدول | |
| نشاط آخر لحظة | آخر ٤٠ حدث بالتفصيل |
| صحة السحب | كل متجر شغال ولا انحظر، والقطع المخفية، والقطع بدون صورة |
| تنزيل البيانات | ملف تفتحه في إكسل |

**الخصوصية:** ما نحفظ عنوان أي زائر. كل زائر ياخذ رقم عشوائي في متصفحه بس، والدولة تجي من كلاودفلير بدون ما نحفظ العنوان. ومن صفحة اللوحة تقدر توقف حساب زياراتك أنت عشان ما تخرب الأرقام.

### التشغيل (مرة وحدة بس)

الإحصائيات تحتاج سيرفر صغير، ونستخدم كلاودفلير لأنه مجاني.

**١. سوّ حساب في كلاودفلير** من هنا:

```
https://dash.cloudflare.com/sign-up
```

**٢. ثبّت نود** (برنامج يشغّل أدوات كلاودفلير). نزّل النسخة اللي مكتوب عليها LTS من هنا وثبتها عادي:

```
https://nodejs.org
```

**٣. افتح الشاشة السوداء داخل مجلد السيرفر:**

```
pc-prices > worker
```

**٤. اكتب الأوامر هذي واحد واحد:**

ثبّت الأدوات:

```
npm install
```

سجّل دخول في كلاودفلير (بيفتح لك المتصفح، وافق):

```
npx wrangler login
```

سوّ قاعدة البيانات:

```
npx wrangler d1 create pc_prices_analytics
```

بيطلع لك سطر فيه رقم طويل بعد كلمة database_id. انسخ الرقم وحطه في هذا الملف مكان الكلام المكتوب بالإنجليزي:

```
worker/wrangler.toml
```

جهّز الجداول:

```
npx wrangler d1 execute pc_prices_analytics --remote --file=schema.sql
```

اختر كلمة سر اللوحة (بيطلب منك تكتبها، وما تطلع على الشاشة وأنت تكتب):

```
npx wrangler secret put ADMIN_PASSWORD
```

ارفع السيرفر:

```
npx wrangler deploy
```

بيطلع لك رابط ينتهي بهالشكل، انسخه:

```
https://pc-prices-analytics.YOUR-NAME.workers.dev
```

**٥. حط الرابط في إعدادات الموقع** في هذا الملف بين علامتي التنصيص:

```
site/config.js
```

**٦. افتح اللوحة** من رابط موقعك وبعده اسم الصفحة:

```
/admin.html
```

## البيسي ثلاثي الأبعاد

خلفية الموقع فيها بيسي بإضاءة RGB مبني بالكود في هذا الملف:

```
site/pc3d.js
```

تقدر تتحكم بوضوحه من الدالة اللي اسمها:

```
fade
```

الرقم الأول لوضوحه فوق، والثاني لما تنزل تحت. ويوقف الرسم تلقائياً لما تكون الصفحة مخفية عشان ما يستهلك الجهاز، ولو المتصفح ما يدعم الرسم ثلاثي الأبعاد الموقع يشتغل عادي بدونه.

## المتاجر المدعومة

| المتجر | الموقع |
|---|---|
| أمازون السعودية | `amazon.sa` |
| نون | `noon.com` |
| طبيب الكمبيوتر | `pcd.com.sa` |
| إنفني أرك | `infiniarc.com` |

وتقدر تضيف أي متجر ثاني بحط روابطه في ملف القائمة، والسكربت يحاول يقرأ سعره تلقائياً.

## كيف يشتغل

١. أنت تحط روابط المنتجات في ملف القائمة.

٢. السكربت يفتح كل رابط ويقرأ السعر من الصفحة.

٣. يختار الأرخص من المتاجر المتوفرة ويحفظ سجل الأسعار السابقة.

٤. الموقع يقرأ ملف البيانات ويعرض كل قطعة مع أرخص سعر ونسبة النزول أو الزيادة ورسم صغير لتغير السعر.

## التشغيل على جهازك

ثبّت المكتبات:

```bash
pip install -r requirements.txt
```

شغّل السكربت:

```bash
python scraper.py
```

افتح الموقع (لازم من خلال سيرفر محلي عشان يقرأ ملف البيانات):

```bash
cd site
python -m http.server 8000
```

بعدها افتح هذا الرابط في المتصفح:

```
http://localhost:8000
```

افحص الروابط بعد ما تعدّل القائمة (يكشف الروابط المكررة أو الغلط):

```bash
python check_links.py
```

شغّل الاختبارات:

```bash
python -m pytest tests
```

## إضافة منتج

افتح صفحة المنتج في المتجر، انسخ الرابط، وأضفه بهالشكل:

```yaml
  - name: "Samsung 990 Pro 2TB"
    category: storage
    links:
      - https://www.amazon.sa/dp/...
      - https://www.noon.com/saudi-ar/.../p/
```

الأقسام المتاحة مكتوبة أعلى الملف وتقدر تضيف قسم جديد.

## النشر مجاناً مع التحديث التلقائي

١. سوّ مستودع جديد في موقع جت هب وارفع فيه ملفات المشروع.

٢. من إعدادات المستودع روح لقسم الصفحات واختر المصدر التالي:

```
Settings → Pages → Source: GitHub Actions
```

٣. من تبويب الإجراءات شغّل سير العمل يدوياً أول مرة:

```
Actions → Update prices → Run workflow
```

٤. بعدها يتحدث لحاله كل ست ساعات، ورابط موقعك يكون بهالشكل:

```
https://USERNAME.github.io/REPO-NAME/
```

## التوفر: الموقع يعرض المتوفر بس

١. لو صفحة المنتج قالت إنه نافد، السكربت ما يخفيه على طول. ينتظر دقيقة ونص ويفحصه مرة ثانية، ولو تأكد إنه نافد يخفيه.

٢. القطعة تختفي من الموقع لو نفدت من كل المتاجر، وأول ما ترجع متوفرة في أي متجر ترجع للموقع تلقائياً.

٣. لو متجر ما رد أو انحظر مؤقتاً، نخلي آخر حالة معروفة. بس لو مر أكثر من يومين بدون ما نتأكد إن القطعة متوفرة، نخفيها احتياطاً.

حالة كل رابط محفوظة في هذا الملف:

```
state.json
```

## الصور

السكربت ياخذ صورة كل قطعة من صفحة المتجر نفسه (أمازون أولاً). ولو ما لقى صورة، يبحث باسم القطعة بالضبط في قوقل، ولو قوقل رفض يبحث في بنق. كل صورة تنحفظ عندك في:

```
site/img
```

عشان ما تختفي لو المتجر غيّر رابطها. في كل تشغيل يجيب ٦٠ صورة كحد أقصى، فأول مرة تحتاج كم تشغيل لين تكتمل.

## الحماية من الحظر

السكربت مصمم عشان ما يضغط على المتاجر:

| الإعداد | قيمته | وش يسوي |
|---|---|---|
| `STORE_GAP` | من ٨ إلى ١٥ ثانية | أقل وقت بين طلبين لنفس المتجر |
| `MAX_PER_STORE` | ١٢٠ | أقصى عدد طلبات لكل متجر في التشغيل الواحد |
| `REFRESH_HOURS` | ٥ ساعات | ما يعيد فحص رابط انفحص قبل هالمدة |

وفوق كذا:

١. المتاجر تتناوب، يعني ما يطلب من نفس المتجر ورا بعض.

٢. أول ما متجر يرفض طلب أو يطلع صفحة تحقق من الروبوت، السكربت يوقفه فوراً لين التشغيل الجاي، ويخلي أسعاره القديمة في الموقع.

٣. لو رابط فشل مؤقتاً، يبقى آخر سعر معروف له بدل ما يختفي.

لأن فيه حد أقصى لكل متجر، أول مرة تشغّل السكربت ممكن ما يجيب كل أسعار أمازون. شغّله مرة ثانية ويكمل الباقي.

لو تبي تفحص كل شي حتى اللي انفحص قريب:

```bash
python scraper.py --all
```

## أشياء مهمة لازم تعرفها

**الحظر:** بعض المتاجر الكبيرة مثل أمازون ونون عندها حماية ضد السكربتات، وأحياناً ترفض الطلبات اللي تجي من سيرفرات جت هب. إذا لاحظت أن متجر معين دائماً يفشل، شغّل السكربت من جهازك بدال ذلك أو استخدم متصفح آلي.

**تغيير تصميم المتاجر:** السكربت يحاول أولاً يقرأ البيانات المنظمة اللي تحطها المتاجر لمحركات البحث، وهذي نادراً تتغير. إذا فشل يرجع لمحددات خاصة بكل متجر في أعلى ملف السكربت، وهذي ممكن تحتاج تحديث إذا المتجر غيّر تصميمه.

**شروط الاستخدام:** راجع شروط كل متجر قبل ما تسحب أسعاره بشكل تجاري. الطريقة الأنظف على المدى البعيد هي الاشتراك في برامج الشراكة اللي توفر الأسعار رسمياً، ومنها:

```
Amazon Associates (Product Advertising API)
```

وبهالطريقة تكسب عمولة كمان على كل عملية شراء من موقعك.
